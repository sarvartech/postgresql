## Tahlil

1. **5–50 client oralig'ida** ikkala server deyarli bir xil natija ko'rsatdi
   (farq 3–7%, statistik shovqin darajasida). Buning sababi: oddiy OLTP
   (TPC-B) yuklamasida ma'lumot hali RAM/OS cache'da, `shared_buffers`,
   `work_mem` kabi parametrlar bu miqyosda katta farq bermaydi — ular katta
   JOIN, sort yoki disk I/O cheklangan holatlarda ko'proq seziladi.

2. **100 client bosqichida Control-node butunlay ishlamay qoldi** — sabab:
   tuning paytida `max_connections = 50` qo'yilgan, lekin test 100 ta
   parallel ulanish ochishga harakat qildi. Default server esa
   `max_connections = 100` (PostgreSQL default qiymati) bilan bemalol
   ko'tardi.

3. Bu natija **production uchun eng muhim dars**: tuning parametrlarini
   ilova/test ehtiyojidan ajratib, "RAM tejash" nuqtai nazaridan tanlash
   xavfli — past yuklamada hammasi yaxshi ko'rinadi, lekin peak yuklamada
   server butunlay so'rovlarni rad eta boshlaydi.
